## About

I am a **Full-Stack AI & Software Engineer** based in Chennai, India. I focus on the intersection of modern web architecture and applied artificial intelligence—building reliable full-stack applications, intelligent agent workflows, and clean user-centric tools.

- 🌱 **Continuous Learning**: Advanced LLM reasoning systems, distributed web architectures, and real-time data pipelines.
